# 힘 단위 변환기

## 프로그램 용도

Tkinter로 만든 GUI 프로그램입니다. 입력한 힘의 값을 다음 단위 사이에서 변환합니다.

- `N` (뉴턴)
- `kN` (킬로뉴턴)
- `kgf` (킬로그램힘)
- `gf` (그램힘)
- `lbf` (파운드힘)

모든 변환은 뉴턴(`N`)을 기준으로 계산합니다. 변환 결과는 화면에 표시되며, `결과 복사` 버튼으로 클립보드에 복사할 수 있습니다. 최근 변환 기록은 최대 5개까지 보입니다. `초기화` 버튼은 숫자 입력과 결과를 지우고, 선택한 단위는 유지합니다.

## 실행 명령

PowerShell 또는 명령 프롬프트에서 이 README 파일과 같은 폴더로 이동한 후 실행합니다.

```powershell
python force_converter_gui.py
```

Python 명령이 환경에 따라 다르면 다음 명령을 사용할 수 있습니다.

```powershell
py force_converter_gui.py
```

## 필요한 환경

- Python 3
- Python 표준 라이브러리 `tkinter`
- 하중 분석 그래프를 사용하려면 `matplotlib`가 필요합니다.
- GUI 창을 표시할 수 있는 데스크톱 환경이 필요합니다.

## 정상 입력 예시

입력창에 `1000`을 입력하고 변환 전 단위를 `N`, 변환 후 단위를 `kN`으로 선택한 뒤 `변환`을 누르면 다음 결과가 표시됩니다.

```text
1000 N = 1.000000 kN
```

변환 후 `결과 복사` 버튼을 누르면 표시된 결과가 클립보드에 저장됩니다.

다른 예시:

```text
1 kgf = 0.009807 kN
```

## 오류 입력 예시

### 숫자가 아닌 값

입력창에 `abc` 또는 `10N`처럼 숫자로 변환할 수 없는 값을 입력하면 다음 오류가 표시됩니다.

```text
숫자를 올바르게 입력하세요.
```

### 변환 단위를 선택하지 않은 경우

변환 전 단위 또는 변환 후 단위가 선택되지 않은 상태에서 변환하면 다음 오류가 표시됩니다.

```text
변환할 단위를 선택하세요.
```

현재 화면에서는 두 단위가 기본값으로 설정되어 있습니다.

## 하중 데이터 분석

### 입력 데이터와 단위

분석기는 같은 폴더의 `load_data.csv`를 기본 입력으로 읽습니다. CSV에는 다음 열이 있어야 합니다.

- `time_s`: 시간(초, `S`)
- `force_N`: 하중(뉴턴, `N`)

응력은 `force_N / AREA_MM2`로 계산하며, 현재 단면적 설정은 `AREA_MM2 = 100 mm²`입니다. 기준 응력은 `6 MPa`입니다.

### 필요한 라이브러리와 실행

```powershell
python load_analyzer.py
```

Python 3와 `matplotlib`가 필요합니다. `csv`, `pathlib`은 Python 표준 라이브러리입니다. `matplotlib`가 설치되어 있지 않으면 다음 명령으로 설치합니다.

```powershell
python -m pip install matplotlib
```

분석기를 실행하면 원본 `load_data.csv`를 덮어쓰지 않고 다음 파일을 생성합니다.

- `load_result.csv`: `time_s`, `force_N`, `stress_MPa` 열을 포함한 계산 결과
- `stress_plot.png`: `Time (s)`-`Stress (MPa)` 그래프
  - 각 유효 데이터는 점과 선으로 표시
  - 최대 응력점은 빨간색으로 표시하고 응력값을 숫자로 표시

실행 결과로 데이터 개수, 제외한 행 수, 유효한 데이터 수, 최대 하중과 해당 시간, 최대 응력과 해당 시간, 기준 응력(`6 MPa`) 초과 데이터 개수를 출력합니다.

### 오류 처리 규칙

`time_s` 또는 `force_N`이 빈칸이거나 숫자가 아니면 원본 CSV의 행 번호와 문제 값을 알리고 해당 행을 계산과 그래프에서 제외합니다. 제외한 행 수와 유효한 데이터 수를 출력합니다. 유효한 데이터가 하나도 없으면 결과 계산과 파일 생성을 중단하고 안내 메시지만 출력합니다. 입력 CSV 파일은 수정하지 않습니다.

오류 처리 실습은 `load_data.csv`를 복사해 만든 `load_bad.csv`로 수행할 수 있습니다. 현재 기본 입력은 원본 `load_data.csv`입니다.
